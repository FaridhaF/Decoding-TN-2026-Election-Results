# Decoding the 2026 Tamil Nadu Assembly Election

## Codebasics Resume Project Challenge

### Project Overview

This project was developed as part of the Codebasics Resume Project Challenge: **Decoding the 2026 Tamil Nadu Assembly Election**.

Using official Election Commission of India (ECI) data, the analysis explores key electoral trends from the 2026 Tamil Nadu Assembly Election through interactive dashboards, storytelling-focused visualizations, and data-driven insights.

### Headline

**The Election That Reshaped Tamil Nadu's Political Balance**

The project focuses on three major stories:

* Geographic Voting Patterns
* Seat Flip Analysis
* Margin of Victory Analysis

## Key Insights

### 1. Geographic Voting Patterns

Explores regional variations in electoral outcomes across Tamil Nadu and highlights how different regions contributed to the final result.

### 2. Seat Flip Analysis

Examines constituencies that changed winning parties between 2021 and 2026, identifying the scale and direction of electoral shifts.

### 3. Margin of Victory Analysis

Analyzes winning margins across constituencies to understand electoral competitiveness and mandate strength.

## Reproducing the Analysis

1. Clone this repository.
2. Open the notebooks located in the `notebook` folder.
3. Ensure the required election datasets are available.
4. Run the notebooks sequentially.
5. Review the generated analysis and visualizations.
6. Explore the Power BI dashboard using the provided link.
