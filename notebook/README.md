# Jupyter Notebooks

This folder contains the Python notebooks used for the analysis of the 2026 Tamil Nadu Assembly Election.

## Notebooks

### Geographic_Story.ipynb

Analyzes regional voting patterns and seat distribution across Tamil Nadu.

### Flip_Story.ipynb

Examines constituencies that changed winning parties between elections and identifies major electoral shifts.

### Margin_of_Victory.ipynb

Analyzes winning margins across constituencies to understand electoral competitiveness and mandate strength.

## Data Source

All analysis is based on publicly available Election Commission of India (ECI) election results data.

## Tools Used

* Python
* Pandas
* Plotly
* Jupyter Notebook

## Note

These notebooks were created as part of the Codebasics Resume Project Challenge: **Decoding the 2026 Tamil Nadu Assembly Election**.
